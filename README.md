# FINE TUNING OF LANGUAGE MODELS FOR EDUCATION

The present repository is for the paper: "Information Retrieval in Learning Materials: Which Language Models Work Best and How to Improve Them"

The code can be used to fine-tune Language Models for a specific set of lecture slides using the methodology proposed in the paper.
We also include code to evaluate the performance of the fine-tuned models when the Ground Truth values are available. 

For new implementations, the main code is located in the notebooks "5. THE MODEL FINE-TUNING" and "7. CROSS_ATTENTION_SEEKER".
